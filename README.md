# Motion Design Lab — Publication Package

A static GitHub Pages-ready portfolio and motion reference site.

## Contents
- **index.html** — homepage with an embedded Playground, searchable 48-item technique catalog, and ten live site palettes.
- **demos/** — original interactive HTML labs (foundation, 32-study grammar, CH02/03, CH04, Color Atlas). Direct public URLs work.
- **assets/** — original demo previews only; no user-supplied third-party references included.
- **catalog/** — structured technique and color system metadata.
- **docs/** — standalone Markdown research and learning materials.

## Deployment
1. Create a new PUBLIC GitHub repository (recommended name: `motion-design-lab`).
2. Upload all the files in THIS folder to the repository root. `index.html` must be in the repository root.
3. GitHub repository > Settings > Pages > Build and deployment > Deploy from a branch > `main` > `/(root)` > Save.
4. Wait until GitHub Pages reports the public URL and open it. Do not treat the expected URL as live until you verify it.
5. Visit the homepage and each of these URLs: `?lab=core`, `?lab=modular`, `?lab=spatial`, `?lab=colors`, `?lab=foundation`.

## Privacy / attribution
Public websites can reveal all included static resources. This package excludes the original uploaded brand reference collages and third-party social media video, and it labels synthetic data as examples. TRA/PRA are descriptive study labels based on image-sampled approximations, not claimed as official brand design systems. Validate any externally credited examples and media rights before later adding them.

## Important
- The Playground embeds the original static demos. Each demo also has a standalone URL. Color Atlas choices preview the homepage theme for the current visit.
- The data catalog includes CH01-CH04 (48 patterns). CH05 / CH06 are planned but not included.
- Files in `docs/` are Markdown; browsers may display them as text. For a polished reader, add a Markdown renderer in a future iteration.
