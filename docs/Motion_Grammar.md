# MOTION DESIGN LAB 02 · 32 种动效设计语法与控制手册

版本：v2.0 · 2026-11-19  
配套交互项目：`Motion_Design_Lab_02.html`（单文件）或 `motion_lab_v2/index.html`（源码包）  
内容结构：4 大领域 × 8 种技法 = **32 项原创可视化 Motion Study**。

> 本手册延续上一版的工业编辑风格、TRA / PRA 起始色板，以及“先静态版式、后运动语法”的工作原则。32 项是可操作的演示课程，不是 32 种互相独立的行业流派。所列时间是课程实验起点，需根据字幕、配音、镜头和具体载体调整。

## 一、使用方法：同一变量先做单次对照

1. 在左上方切换 Typography / Graphic / Information / Art Direction，进入一个技法。
2. 在预览区播放、暂停或拖动 5.2 秒时间轴，观察运动全过程，而非只看设计终帧。
3. 在右侧调节主标题、色板、能量、入场时长、stagger、缓动与主方向。**每次只改一个变量**，记录与前一版本的差异。
4. 阅读三段配方：Visual Structure / Behavior / Timing，再核对设计意图与常见错误。
5. 点击 COPY PROMPT，提交给 Codex 或 Cursor 先做 5 秒 Motion Study；可下载 JSON Motion Tokens 作为工程参数表。

**重要的区别**：网页播放器展示的是设计意图的可编辑原型，不是直接可渲染为最终成片的 Remotion 项目。移植时，应把界面语法和镜头参数转成 Remotion 组件或 GSAP Timeline。严格保护输入事实，不让 AI 生成未经校验的数字。

## 二、统一的动效描述规范

一次可执行的 Motion 请求至少包含以下信息：

| 层级 | 必须描述什么 | 可以量化的字段 |
|---|---|---|
| A. Communication Goal | 这一镜头要解释什么 | 一屏一个中心结论；对比维度与阅读顺序 |
| B. Layout System | 平面结构 | 16:9 / 9:16、安全边距、列数、字号比例、对齐规则 |
| C. Motion Hierarchy | 主运动与静止参照 | 主体/辅助运动组、静态坐标、遮罩对象 |
| D. Motion Mechanics | 动作类型 | 方向、起点/终点、裁切路径、距离、共享锚点 |
| E. Timing | 时间关系 | 持续时长、错位、缓动、保持与退场 |
| F. Art Direction | 色彩与材质 | 4 色以内、配色角色、线宽、纹理与光影比例 |
| G. QA | 验收依据 | 字符可读、数据真实、比例正确、运动方向一致 |

默认实验参数（不是行业硬性标准）：`1920×1080 / 30fps / 12列网格 / 6%安全边距 / 入场540ms / stagger100ms / 完整停留1.5s / cubic-bezier(0.18,0.82,0.19,1)`。

## 01 · Typography Motion / 文字动效

文字本身承担视觉运动。先确认字体/换行/基线，再决定遮罩方向、运动距离与字距。

**训练方式**：同一主标题「三种出海路径」，保持平面网格不变，逐一比较遮罩升入、阶梯错位、字距收束和巨型裁切。记录“哪一种更适合配音进入”的判断。

### TY01 · Masked Baseline Reveal / 行遮罩·基线升入

**核心作用：** 文字沿基线进入固定裁切框，真正移动的是字形，不是容器。

- **平面版式**：固定主标题位置；用独立 overflow-hidden 文字行建立精确对齐。
- **运动规则**：从行框底部沿 Y 轴上移；两行或多个短语按阅读顺序依次入场。
- **时间建议**：单行 480–620ms；行间错位 80–120ms；完成后保持至少 1.3s。
- **适用内容**：高密度信息中只让主标题动；利用静止的网格和注释形成速度对比。
- **避免误区**：不要让背景、容器与文字一起漂移；避免逐字弹跳和整体淡入。

### TY02 · Staggered Word Cascade / 单词阶梯错位

**核心作用：** 三个短词逐级出现；运动顺序就是阅读顺序。

- **平面版式**：三行文字左对齐，重心沿纵向推进；细标尺只辅助定位。
- **运动规则**：按组序列 stagger；后一组应在前一组快完成时进入。
- **时间建议**：默认每行 540ms，错位 100–160ms；最终集体保持。
- **适用内容**：特别适合一个问题的三段论、三个策略或品牌主张。
- **避免误区**：不要把每个字母单独弹出；不要让错位过大导致失去词组关系。

### TY03 · Tracking Compression / 字距收束

**核心作用：** 用字体间距收紧表达“聚焦”，是无需大位移的微观动效。

- **平面版式**：中心大词、精密线框与极小辅助标签构成压缩式版面。
- **运动规则**：tracking 从松散向紧凑变化；可叠加轻微透明度，但不依赖缩放。
- **时间建议**：约 700–1000ms；缓动需稳定；结束字距按字体实际视觉微调。
- **适用内容**：适合技术性、理性、专业的章节标题与终幕字标。
- **避免误区**：不要大幅度压扁字宽来冒充字距；避免中文字体被拉伸。

### TY04 · Editorial Crop Type / 超大字裁切

**核心作用：** 大字号越过画布边界，利用裁切制造杂志感与尺度对比。

- **平面版式**：巨型主词占据主要视觉面积，辅助文字只在一角保留。
- **运动规则**：文字从窗口边缘滑入；版面自身对溢出负责；出场可由同向色块擦过。
- **时间建议**：入场 450–700ms，信息保持 1300ms 以上。
- **适用内容**：适合章节间强节奏切换、品牌宣言及封面式开场。
- **避免误区**：切勿让核心字词失去可辨认性；裁切要有明确对齐与视觉意图。

### TY05 · Type Grid Reflow / 字块重排

**核心作用：** 多组短标题从独立单元形成一个整体信息网格。

- **平面版式**：三列卡片共享基线、间距与字体系统。
- **运动规则**：先建立分栏，再让每个字块通过位移和揭示进入目标单元。
- **时间建议**：网格先建立约 300ms，字块错位 90ms；收束后留屏。
- **适用内容**：适合多品牌比较、三类概念、双语标题结构。
- **避免误区**：不要在网格未形成之前就显示全部文字，也不要任意改变字号。

### TY06 · Numeric Typography / 数字计数排版

**核心作用：** 数字既是信息，也是强势的排版主角。

- **平面版式**：一个超大数字、一个清晰单位、一个必要来源/说明层级。
- **运动规则**：标题先稳住基线；数字从 0 计到示例终值；单位在结尾短暂揭示。
- **时间建议**：计数 700–1200ms，最终数值额外停留 1.5s。
- **适用内容**：适合增长、累计、里程碑、渗透率等单一重要 KPI。
- **避免误区**：不要以动画数值替代核验数据；不能让数字跑到错误的百分比或单位。

### TY07 · Split-Line Composition / 文字分屏拼接

**核心作用：** 两组文字共享栅格并对位，形成对比关系。

- **平面版式**：画面横向二分，各自内容在本侧的裁切窗口出现。
- **运动规则**：两侧沿不同轴向进入，但最终严格匹配标题基线。
- **时间建议**：两组动作相差 100ms 内；完成后需要完整比较窗口。
- **适用内容**：适合 BEFORE / AFTER、LOCAL / GLOBAL 等对照。
- **避免误区**：避免上下左右同时乱动；两侧字号与留白不能失衡。

### TY08 · Typography as Transition / 大字作为转场

**核心作用：** 让标题成为转场的色块或遮罩，而非转场结束后才出现。

- **平面版式**：超大单词横贯舞台，字形周围有大块干净背景。
- **运动规则**：先出现文字，接着大色块从同方向覆盖，完成场景逻辑过渡。
- **时间建议**：标题 450ms、色块 550ms、下一镜头根据共享锚点承接。
- **适用内容**：适合片头到第一章节、结论到案例、品牌与数据段落衔接。
- **避免误区**：不要用纯闪白或无缘由拉伸替代设计过渡。

## 02 · Graphic Motion / 图形与转场

图形运动主要用于串联信息：模块保持尺寸连续、锚点保持空间连续、转场保持方向连续。

**训练方式**：用同一张三栏比较卡，先用矩形裁切显示，再改成基线引导与共享锚点转场。不能因为换动画而改写全部网格。

### GR01 · Modular Card Cascade / 模块卡片递进

**核心作用：** 把静态卡片的网格逻辑转换成有顺序的色块揭示。

- **平面版式**：三列固定宽度卡片；统一外边距、内边距与底部标签。
- **运动规则**：每列由矩形裁切从左到右依次打开，文本在块内二次入场。
- **时间建议**：卡片 480–660ms，列错位 90–130ms。
- **适用内容**：适合产品特征、三家品牌策略、功能模块等多栏目叙事。
- **避免误区**：禁止卡片随机飞入、不同列使用不同转场、阴影层级失控。

### GR02 · Axis-Led Wipe / 基线引导擦除

**核心作用：** 用一条水平基线把新旧内容接起来，使转场有原因。

- **平面版式**：水平线横贯网格，下一信息块的起点依附于同一基线。
- **运动规则**：细线延展→矩形色块沿轴生长→文字进入色块。
- **时间建议**：线 400ms、色块 600ms、文字 450ms，允许叠加。
- **适用内容**：适合图表开场、章节切换、信息面板连接。
- **避免误区**：不使用无来源的扫描光束、镜头抖动或随机粒子。

### GR03 · Geometric Morph / 几何形态变换

**核心作用：** 一个几何对象在位置不漂移的情况下切换轮廓语义。

- **平面版式**：主形状居中，标签和标尺静止，对比观察形态变化。
- **运动规则**：圆角从 50% 收束为切角矩形；尺寸和中心位置保持连续。
- **时间建议**：形态过渡 650–900ms；变化后的状态保持。
- **适用内容**：适合图标状态变化、产品模块的抽象表达。
- **避免误区**：切忌体积突然消失或颜色、位置、形状同时改变造成识别困难。

### GR04 · Match-Move Anchor / 共享锚点转场

**核心作用：** 上一元素的空间位置变成下一元素的起点。

- **平面版式**：保持共享坐标位置：横线、起点标记或指标标签。
- **运动规则**：先延伸共享基线，再揭示新图表或卡片，不清屏硬切。
- **时间建议**：共享元素动作 400–700ms，下一场延迟约 100ms。
- **适用内容**：适合从宏观概念进入具体数据、地图进入指标卡。
- **避免误区**：不要断开线条或随意改变坐标，以致观众丢失空间参照。

### GR05 · Grid Reconfiguration / 网格重组

**核心作用：** 一组独立模块在同一二维坐标系内重排。

- **平面版式**：严格定义 4×3 网格；卡片移动后边缘与间距统一。
- **运动规则**：每个模块从明确的离散位移回到目标网格；线性移动叠加轻微错位。
- **时间建议**：主体移动 550–850ms；最多两组节奏。
- **适用内容**：适合分类重排、抽象系统架构与信息归档。
- **避免误区**：避免随机散开、重叠遮挡文字、模块尺寸不守网格。

### GR06 · Layered Parallax / 分层视差推移

**核心作用：** 通过不同层次的速度制造轻量深度，不一定需要 3D 引擎。

- **平面版式**：前景主卡、次级细节与背景线稿保持明确层次。
- **运动规则**：相同方向但不同距离的平面位移，前景幅度大于背景。
- **时间建议**：400–800ms；背景速度约前景的一半作为实验起点。
- **适用内容**：适合汽车摄影+信息叠加、品牌页面、轻量 2.5D 场景。
- **避免误区**：不要让景深或视差干扰文字阅读；背景不能突然反方向滑走。

### GR07 · Editorial Split Screen / 编辑式分屏转场

**核心作用：** 把一个叙事场景拆成左右两个相互呼应的视觉区域。

- **平面版式**：左右 52/48 分割；色块、标题、辅助指标统一对齐。
- **运动规则**：两块从相反方向裁切入场，局部文字随后出现。
- **时间建议**：左右区域间隔 80ms，字幕跟随 120ms。
- **适用内容**：适合产品与环境、策略与结果、过去与未来的并置。
- **避免误区**：不要做无意义 3D 翻页，也不要每次分屏都重新定义基准线。

### GR08 · Shape-to-Label / 图形扩展为信息标签

**核心作用：** 把点、线、面演化为一条可以承载信息的注释条。

- **平面版式**：单个图标连接到长条标签，背景主体保持静止。
- **运动规则**：先确定几何起点，再横向伸展，文字经裁切露出。
- **时间建议**：图形 300ms、伸展 500ms、文本 350ms。
- **适用内容**：适合地图标注、车身结构标识、交互式说明。
- **避免误区**：避免标签出现前线条乱窜；标注不能与目标位置断开。

## 03 · Information Design / 数据与信息动效

图表是一种信息编码。数据单位、坐标、比例尺、时间、来源准确性，优先级高于运动表现。

**训练方式**：使用自备真实数据或明确声明的虚拟演示数据，用同一数据集分别做比较条、KPI 与趋势图。写出每种图表有效传达和无法传达的结论。

### IN01 · Comparative Bar Build / 比较条形图

**核心作用：** 先明确比较维度，再按一致零基线建立可读的数据条形。

- **平面版式**：分类标签左对齐，所有条形共享零点与比例尺。
- **运动规则**：轴线先出现，三组条形按序延展到示例值，最终数值停留。
- **时间建议**：轴线 200ms、条形约 600ms、每组错位 110ms。
- **适用内容**：适合对比不同地区、不同品牌在同一指标上的差异。
- **避免误区**：严禁不同量纲混排，严禁为戏剧性随意截断零点。

### IN02 · Synchronized KPI Counter / 指标计数群组

**核心作用：** 数字与文字的优先级统一；多个 KPI 共同构成横向信息结构。

- **平面版式**：三列 KPI，数字最大、指标次之、单位最小。
- **运动规则**：背景卡片稳定；数字分别计到示例目标；最终统一停留。
- **时间建议**：数字计数 700ms，错位约 90ms，停留至少 1.5s。
- **适用内容**：适合首页指标、章节总结、业务规模概览。
- **避免误区**：不得以模糊/乱跳数字营造假“科技感”；同屏计数需有同步关系。

### IN03 · Line Chart Draw-on / 折线增长揭示

**核心作用：** 趋势要由坐标、刻度、曲线与关键点共同说明。

- **平面版式**：坐标轴固定，曲线在独立 SVG 路径中绘制，末端数字标注。
- **运动规则**：先显示坐标系，再用 path length 绘制走势，关键点依次出现。
- **时间建议**：轴线先行 300ms、曲线 850–1200ms、末端注释 300ms。
- **适用内容**：适合趋势变化、阶段增长、历史比较。
- **避免误区**：不要省略纵轴意义，也不要将虚构数据当作真实结论。

### IN04 · Dot-Matrix Distribution / 点阵分布递进

**核心作用：** 通过重复标记形成整体与局部的数量感。

- **平面版式**：点阵规则排列，重要一组与其他组通过颜色而非尺寸区分。
- **运动规则**：按列逐步点亮，先看总体，再强调一个子集。
- **时间建议**：点阵分组 40–80ms，最终维持完整状态。
- **适用内容**：适合类别占比、群体概念、模块完成度。
- **避免误区**：面积/点数必须与数据一致；示例点阵不可冒充统计事实。

### IN05 · Milestone Timeline / 时间轴节点

**核心作用：** 用一致尺度和明确先后顺序讲述多个里程碑。

- **平面版式**：横轴上四个节点均匀分布；节点名称与标注距离一致。
- **运动规则**：主线从左至右生长，节点按先后揭示，最后突出当前节点。
- **时间建议**：主线约 1000ms，节点间隔 250–350ms。
- **适用内容**：适合品牌历程、出海进入顺序、技术路线。
- **避免误区**：不应把非等距年份画成等距时间轴而不做说明。

### IN06 · Slope Graph Comparison / 坡度变化比较

**核心作用：** 用线的斜率强调起点与终点之间的相对变化。

- **平面版式**：左右两列是同一组量纲与范围，连线映射相同标签。
- **运动规则**：先出现左右端点，再绘制连接线，最后突出最重要变化。
- **时间建议**：端点 300ms、连接线 650ms、强调约 250ms。
- **适用内容**：适合同一指标的前后比较与排名变化。
- **避免误区**：必须区分百分数变化与百分点变化，杜绝任意调整纵轴。

### IN07 · System Flow Reveal / 系统流程逐级揭示

**核心作用：** 将多步骤的因果或输入输出关系拆解为流动的路径。

- **平面版式**：左中右三阶段固定，箭头与文字对应；避免跨线。
- **运动规则**：节点先稳定，连接线按逻辑方向生长，然后重点节点高亮。
- **时间建议**：阶段延迟约 200ms，主链接约 600ms。
- **适用内容**：适合供应链、本地化生产、渠道结构与技术流程。
- **避免误区**：不要把“相关性”画成“因果链”，不要让箭头与逻辑相反。

### IN08 · Hierarchical Treemap / 矩形分布层级

**核心作用：** 以面积关系组织构成，但层级与标签优先于特效。

- **平面版式**：同一容器内使用嵌套矩形与标题标签，面积比例保持一致。
- **运动规则**：先形成整体边框，分组按面积逐个出现，最终显示名称。
- **时间建议**：模块 500–800ms，错位 120ms。
- **适用内容**：适合预算结构、业务构成、区域分布。
- **避免误区**：若尺寸编码真实数据，面积必须精准映射；不能用设计占位比例发布。

## 04 · Motion Art Direction / 风格与美术指导

美术指导统一控制色彩、字级、网格、材质、运动速度和情绪。风格不是加滤镜，而是改变可视化的组织原则。

**训练方式**：将「一家车企的海外战略」这一抽象主题分别采用 TRA 工业、PRA 编辑、Swiss 克制和 Footage-led 影像四种风格制作静帧，再为每一帧制定对应运动语法。

### AD01 · Industrial Signal / 工业操作手册

**核心作用：** 酸绿、炭黑、安全橙与工程栅格，强调系统、可靠与精密。

- **平面版式**：16:9 / 12 列网格；断角技术框线；极细辅助标签与高对比超粗字。
- **运动规则**：线条扫描→模块展开→技术标签揭示，背景保持稳定。
- **时间建议**：理性节奏，尽量 500–800ms 以内，禁止弹性过冲。
- **适用内容**：汽车技术、工业产品、工程科普、赛车车辆参数卡。
- **避免误区**：杜绝发光描边、假 HUD、无意义复杂线路和随机故障效果。

### AD02 · Electric Editorial / 电蓝荧黄编辑设计

**核心作用：** 电蓝与荧黄大块碰撞；以巨型字级、裁切图形和色块重组为主要语言。

- **平面版式**：大胆且严格的非对称网格，正文少而准确，标题有强视觉势能。
- **运动规则**：超大字体遮罩、色块擦除、模块重组，统一横向全局运动。
- **时间建议**：相对利落的快切，进入 350–550ms，保持 1200ms。
- **适用内容**：商业科技、财经视频、消费品牌广告及栏目包装。
- **避免误区**：不能只有高饱和颜色而没有排版纪律；禁止炫目闪屏。

### AD03 · Quiet Swiss Grid / 克制瑞士网格

**核心作用：** 留白、黑色无衬线与少量高纯度强调色，重视逻辑与比例。

- **平面版式**：精密十二栏、明确左对齐、强烈字级差；不堆装饰。
- **运动规则**：轻量滑移、基线扩展与慢一点的字距变化。
- **时间建议**：进入 600–900ms，延长阅读停留；尽量避免额外特效。
- **适用内容**：品牌战略、研究报告、高端作品集及产品故事。
- **避免误区**：“简约”不是信息不足；不能让主次级字号全部相同。

### AD04 · Monochrome Newsroom / 黑白新闻编辑

**核心作用：** 黑白对比、新闻版式、粗体数据字和少量警示标记。

- **平面版式**：清晰页眉页脚、可追溯日期/来源位置、有限色彩。
- **运动规则**：版面切换优先线性擦除和标题升入，不做新闻花字噪音。
- **时间建议**：快但稳定的 400–650ms 过渡。
- **适用内容**：金融新闻、产业动态、案例拆解。
- **避免误区**：新闻表达不能用视觉动效制造超出证据的确定性。

### AD05 · Footage-led Overlay / 真实影像 + 编辑图形

**核心作用：** 优先保持真实影像摄影品质，只用必要的平面注释增强信息。

- **平面版式**：保留摄影画面主体，标题置于负空间，数据标签对齐安全区。
- **运动规则**：影像可以小幅视差；文字与线框分层进入。
- **时间建议**：字卡 450–700ms，说明性注释比主标题后 100ms 出现。
- **适用内容**：实拍赛车、工厂、采访、纪录片和品牌影像。
- **避免误区**：禁止让图形遮住主体，拒绝过量文字和强磨皮/HDR素材。

### AD06 · Spatial Technical / 2.5D 空间技术

**核心作用：** 3D 物件与二维注释并存，使用透视、层次和技术标注制造空间理解。

- **平面版式**：空间主物件 65%，信息注释位于空间外侧；标注深度逻辑一致。
- **运动规则**：分层视差+共享锚点；信息线始终连着正确结构部位。
- **时间建议**：主物件 850ms，技术标注 450ms，稳定留屏。
- **适用内容**：车辆结构、硬件产品、机械技术解释。
- **避免误区**：不为立体感扭曲真实车辆尺寸，不让标签随摄像机漂移。

### AD07 · Tactile Minimalism / 触感极简

**核心作用：** 低饱和背景、柔和材料、简洁几何和节制的物理感。

- **平面版式**：少量物件、留白与优雅字级；用材质差异提供层次。
- **运动规则**：柔缓位移和微弱压缩回弹，但保留单一主要运动。
- **时间建议**：约 750–1100ms，柔和平滑。
- **适用内容**：消费电子、生活方式品牌、产品概念演示。
- **避免误区**：避免胶皮感、大幅果冻抖动以及无意义的弹簧。

### AD08 · Motorsport Broadcast / 赛车信息系统

**核心作用：** 高对比安全橙、赛道网格、简洁技术曲线，强调速度与可靠参数。

- **平面版式**：车型或抽象车辆为中心，速度/结构信息有明确角标位置。
- **运动规则**：水平高速擦除、工程线延展、快而准的数字切换。
- **时间建议**：入场 320–540ms，核心参数至少留屏 1.4s。
- **适用内容**：GT3、WEC、汽车产品科技与赛事视频。
- **避免误区**：不能伪造赛事数据，不能用动态镜头破坏车型真实比例。

## 三、Motion Art Direction：五组互相约束的 Design Tokens

建议把一个风格定义成一套有内在逻辑的约束，而不是单独的色彩标签。

| 维度 | TRA · Industrial | PRA · Electric | Swiss · Quiet | Footage-Led · Hybrid |
|---|---|---|---|---|
| 主背景 | 炭黑 `#242424` | 电蓝 `#003CF5` | 暖白 `#F3F2EB` | 真实影像/深色叠底 |
| 主强调色 | 酸绿 `#D9FA39` | 荧黄 `#F7FF00` | 少量橙 `#FF5B35` | 与素材固有色呼应 |
| 辅助强调 | 安全橙 `#FF6500` | 黑白对比 | 黑灰层级 | 图形标注色 |
| 字级策略 | 超粗大字＋微型技术标签 | 极大标题/数字和大色块 | 强对齐与留白 | 贴合真实画面负空间 |
| 网格策略 | 工业面板与技术标尺 | 强烈的编辑式非对称网格 | 严格 12 列、间距稳定 | 主体摄影安全区优先 |
| 运动策略 | 精密揭示、结构延展 | 模块擦除、标题裁切 | 克制过渡、缓慢收束 | 平面注释与小范围视差 |
| 禁用特征 | 假 HUD / 发光线 / 机械噪声 | 闪屏 / 高纯度色失控 | 空洞留白 / 层级模糊 | 遮挡主体 / 失真 / HDR 风 |

注意：这里的色板基于用户参考做创作提取，不是 TRA / PRA 原品牌规范数值。

## 四、给 Codex 的通用 Motion Art Director 提示词

```text
你是资深 Motion Art Director 和 Remotion 动画工程师。

目标：针对我提供的内容，先完成一个 5–6 秒高完成度 Motion Study，而不是直接制作完整视频。

请严格按以下步骤工作：
1. 先做一张没有动画的 Style Frame，检查主标题字级、信息优先级、网格对齐、色彩角色与留白。
2. 写出 Motion Grammar：每个运动组的视觉功能、精确起终点、方向、遮罩类型、持续时间、stagger、easing 和可阅读停留时间。
3. 把动效限制在最多两组主运动对象，其余结构保持静止或仅进行辅助过渡。
4. 保证每个段落有进入 / 阅读 / 退出三个状态，预览和离线输出的时间映射一致。
5. 输出 0%、25%、60%、100% 的关键帧；如果完成帧漂亮但运动过程混乱，视为未通过。
6. 优先使用 SVG、CSS transform/clip-path、Remotion interpolate 和可复用组件。只有明确的立体结构与物理视差需求才使用 Three.js/Blender。
7. 保留标题、数据、图表、色板和时间轴的可编辑性。禁止硬编码不实数据；所有统计信息必须有来源。

美术方向：Industrial Editorial Motion / Swiss Grid / Data-Driven Motion。
禁用：模板式 PPT 飞入、粒子、莫名镜头抖动、随意发光、未经解释的 3D 翻转、毫无意义的弹性、过密辅助文字。
先交付 Style Frame + 5s Proof + Motion Tokens + QC 报告，经确认后再批量制作整片。
```

## 五、以《中国车企出海》为例：22 秒微型章节的动效方案

**传播目标**：让观众理解「不同中国新势力车企，采用的海外进入路径不一样」，不要凭未经证实的数据推导具体结论。用一个真实的数据来源先构建比较维度，然后才组织画面。

| 时长 | 技法组合 | 美术与镜头行动 | 信息校验 |
|---|---|---|---|
| 0–4 s | TY01 / TY08 | 大标题「三种出海路径」遮罩入场，色块延续到下一镜头 | 标题应是描述，不预判孰优孰劣 |
| 4–9 s | GR01 / TY05 | 三栏比较布局渐次打开；第一层只显示公司与比较维度 | 公司名称、品牌标识核实 |
| 9–15 s | IN05 / IN07 | 根据真实资料呈现不同阶段和主要进入方式 | 事件时间、合作模式、市场状态核实 |
| 15–19 s | IN01 / IN06 | 仅在拥有可比统计数据时使用横向条或坡度图 | 统一年份、币种、口径、样本 |
| 19–22 s | GR04 / TY04 | 提取一句结论形成大字页，再转换到下一章节 | 区分事实与观察判断 |

**注意**：用不同运动语法连接同一套内容，不意味着每秒都要有新特效。章节中应建立足够长的阅读停留窗口，配音应决定镜头重点。

## 六、Remotion、GSAP、SVG、Three.js 的分工建议

- **Remotion**：视频输出主时间轴、逐帧控制、配音与字幕同步、横竖版复用，动画随帧数确定。
- **GSAP**：网页交互与复杂序列编排，适合作品集体验、可点选动画与滚动驱动，不等同于自动的视频编码器。
- **SVG**：准确绘制折线图、模块连接、图标和技术标注；文本设计需要注意字体和导出一致性。
- **Three.js / Blender**：车辆、机械和空间的可信几何结构；应将数据文字、标注和静态识别层留给 2D 系统。
- **普通 CSS / Web Animations**：轻量的遮罩、位移、尺寸、颜色与过渡，可用于迅速验证设计，不必总借助外部库。

## 七、QC：用于逐项打分的审核量表

每项 0–5 分，满分 30 分；这是一种内部设计复盘工具，不是行业强制标准。

1. 视觉层级：静止帧可否 2 秒读懂主信息？
2. 对齐和网格：不同镜头是否保持统一的空间约束？
3. 动作必要性：每一处运动都在解释信息或维持连续性吗？
4. 节奏与阅读：动画能否与配音协同，而非相互抢夺注意力？
5. 数据与素材准确性：数据口径、数字、轴线、车辆结构是否可靠？
6. 可复用性：换掉文案、数据、素材后，是否保持设计系统稳定？

**硬性退回项**：重要信息遮挡或缺字、图表比例不正确、虚构数据冒充真实、重要车辆几何被不成比例拉伸、因运动混乱而使含义改变。无论总分多少，都需先修复。

## 八、建议练习顺序（四轮，每轮一个短实验）

- 第一轮 TY01、TY02、TY03：同一标题，三种排版动作；练习用控制词描述速度/方向/遮罩。
- 第二轮 GR01、GR04、GR07：同一三栏设计，三种转场；练习视觉锚点保持与栅格连续。
- 第三轮 IN01、IN03、IN05：同一组有来源数据，比较图与时间结构；练习“准确性先于戏剧性”。
- 第四轮 AD01、AD02、AD03、AD05：同一静态内容四种风格；练习从色彩、字级、材质和运动统一做美术指导。
