# Motion Design Lab · Industrial Color Systems / 01

> 配色资料库（2026-11-21）。TRA/PRA 来自用户参考图片的代表色采样，并非官方颜色规范；其余八套为原创创作色板。

## 基础原则

- 不把项目名误认为设计流派：TRA 是自主步行设备的视觉标识；PRA 图片呈现 Predictive Analytics 的品牌视觉。
- 先定义颜色角色：Background / Text / Primary Signal / Accent / Surface / Paper，再定义具体色值。
- 品牌强调色、数据类别色、状态警示色不应混为同一个语义。
- 纯高饱和色更适合章节切换、短时视觉高潮；持续阅读的图表更适合中性色承载。
- 普通文字推荐 WCAG AA 4.5:1，较大文字 3:1，关键非文字图形 3:1，仍需人工检查复杂背景与动态混色。
- 建议比例属于 Motion Lab 设计推荐，并非原作的色彩用量测量。

### TRA-01 · Signal Lime / 工业信号绿
- 来源：参考图采样
- 视觉气质：精密 / 工业设备 / 安全识别
- 适配：工业产品、机械说明、车辆技术视频
- 建议视觉比例：65% 深灰 / 25% 荧光绿 / 7% 陶瓷白 / 3% 警示橙
- 视觉指导：TRA 的真正逻辑是“高亮作为功能层”。大面积酸绿适合章节封面，长时间播放的参数面板更应使用深灰底。
- 动效指导：图形边框先建立，再由黄绿填充信号区，橙色只在异常状态或章节结论短暂出现。

### PRA-02 · Electric Index / 电蓝荧光黄
- 来源：参考图采样
- 视觉气质：数字 / 数据 / 激进编辑
- 适配：财经、车企出海、市场比较、栏目片头
- 建议视觉比例：50% 电蓝 / 28% 酸黄 / 17% 数字白 / 5% 黑
- 视觉指导：PRA 并非蓝色背景上加黄色点缀，而是让蓝黄成为交替的两个大画面状态。黑白用于文字和数据的阅读层。
- 动效指导：利用电蓝与酸黄的整面交换形成强节拍；数据对齐时保持白底作为阅读缓冲。

### NEW-03 · Hazard Protocol / 安全协议橙
- 来源：原创延展
- 视觉气质：工业警示 / 冲击 / 实用
- 适配：工厂、物流、工程机械、赛事维修
- 建议视觉比例：68% 炭黑 / 22% 亚白 / 8% 橙 / 2% 灰
- 视觉指导：橙色的意义是功能、执行与注意。不要让橙色代表所有“好看”的元素，否则警示层级失效。
- 动效指导：用窄条橙色框选变化值；白色图形优先建立结构，橙色最后作为信号切入。

### NEW-04 · Cryogenic Interface / 低温仪器青
- 来源：原创延展
- 视觉气质：实验 / 精密 / 冷静
- 适配：电池技术、传感系统、材料科普
- 建议视觉比例：70% 深石油蓝 / 20% 冷白 / 8% 青绿 / 2% 琥珀
- 视觉指导：偏青的荧光色降低科幻感，偏向精密测量设备。琥珀色仅作为警戒或待校准状态。
- 动效指导：曲线先以冷白轮廓出现，青色从路径端点生长，异常点以琥珀色短暂闪现。

### NEW-05 · Graphite & Copper / 石墨与铜
- 来源：原创延展
- 视觉气质：高端 / 材料 / 工艺
- 适配：汽车品牌、机械质感、工业精品展示
- 建议视觉比例：62% 石墨黑 / 25% 暖白 / 10% 铜色 / 3% 钢灰
- 视觉指导：用低饱和金属色替代荧光，对高端产品更稳妥。真实铜材质的高光与阴影，应由材质系统表现，而非文字色渐变。
- 动效指导：偏慢的遮罩开合和局部高光移动；减少快速闪烁，重点保留材料的重量感。

### NEW-06 · Ceramic Precision / 陶瓷精工
- 来源：原创延展
- 视觉气质：现代 / 洁净 / 结构
- 适配：高级产品手册、智能硬件、作品集网站
- 建议视觉比例：68% 陶瓷米白 / 22% 墨黑 / 8% 钴蓝 / 2% 薄荷绿
- 视觉指导：用明亮中性底构造工程感，钴蓝负责功能和交互。不要把所有按钮都变成蓝色块，避免企业 SaaS 模板化。
- 动效指导：近乎无弹性的细线、偏移和裁切，适合慢节奏的平面信息叠加真实产品照片。

### NEW-07 · Marine Instrument / 海洋仪表绿
- 来源：原创延展
- 视觉气质：航海 / 工程 / 环境监测
- 适配：地理信息、航运、能源与海洋工程
- 建议视觉比例：70% 深海绿 / 20% 雾白 / 8% 海沫青 / 2% 暖橙
- 视觉指导：以深海绿替代纯黑形成场景氛围，青绿负责导航和定位。背景深度变化应克制，不能损失地理数据的精确对比。
- 动效指导：适合地图路径、节点逐步揭示和沿水平轴推进的技术说明。

### NEW-08 · Expedition Olive / 远征橄榄
- 来源：原创延展
- 视觉气质：野外 / 军工 / 地形
- 适配：拉力赛、探险、野外设备、军模技术页
- 建议视觉比例：60% 深橄榄 / 28% 沙色 / 9% 琥珀 / 3% 苔绿
- 视觉指导：不靠夸张的迷彩贴图，而用军用仪表的哑光色阶和自然材料色表达耐候性。
- 动效指导：使用低速滑移、里程标记、地形线图；橙色仅强调关键里程或警告。

### NEW-09 · Thermal Register / 热成像记录
- 来源：原创延展
- 视觉气质：热流 / 能量 / 精密监测
- 适配：动力系统、能源、热管理与故障分析
- 建议视觉比例：67% 深棕黑 / 20% 暖白 / 10% 热红 / 3% 琥珀
- 视觉指导：热红与琥珀可形成温度叙事，但真实热力图不能用品牌渐变代替有物理意义的温度编码。
- 动效指导：用带单位的温度节点、局部热区揭示和曲线追踪，而非满屏红色警报。

### NEW-10 · Orbital Violet / 轨道紫
- 来源：原创延展
- 视觉气质：空间 / 前瞻 / 高技术
- 适配：未来出行、卫星、空间技术与展会片头
- 建议视觉比例：70% 深靛蓝 / 18% 浅白 / 10% 紫 / 2% 荧光绿
- 视觉指导：保持紫色的清晰形体，不要用大量辉光或渐变掩盖结构。适合轻空间层次与高对比的图形排版。
- 动效指导：用深度错层和缓慢的轨迹线衔接二维与三维，荧光绿只点亮核心事件。

## Codex 配色控制母提示词

请先设计 1920×1080 的静态 Style Frame，采用选定的配色系统与 12 列设计网格。严格遵守 Background / Text / Primary Signal / Accent / Surface / Paper 的色彩角色，保持数据类别色与品牌强调色分离。分为 3 个动态状态：建立结构、信息揭示、阅读保持。强信号色的覆盖范围要根据观看时长调整；禁止满屏高饱和色长期持续。输出色彩 Token、关键帧、可复用样式，并检查文本、图形和图表语义。
